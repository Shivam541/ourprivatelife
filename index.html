Our Private Life

No app backend, database, or TURN relay is used. Manual copy-paste signaling keeps setup server-free.

Important: this version uses Google's public STUN service only to discover network candidates, which makes direct calls across different cities much more likely. Call media is still peer-to-peer when a direct connection succeeds. Some restrictive networks use symmetric NAT and will still fail without a TURN relay. GitHub Pages only hosts this page; it is not part of the call.
